# Один VPS и один купленный прокси

1. С другого устройства подключись по SSH к нужному VPS с Debian 12 или 13. Войди как `root` или выполни `sudo -i`.
2. Выполни строку из [COMMAND.txt](COMMAND.txt). Мастер сам определит адрес VPS и выберет свободный порт для подключения.
3. Вставь **одну строку из кабинета продавца**. Для SOCKS5 с авторизацией по IP VPS достаточно `IP:порт`. Для SOCKS5 с паролем вставь `IP:порт:логин:пароль`. Если выбрал HTTP, добавь `http://` в начало и используй именно HTTP-порт. Вставка скрыта, после неё нажми Enter.
4. Мастер проверит выход через прокси. Когда увидишь ожидаемый адрес, введи `INSTALL`. Если у прокси отдельный шлюз, чей адрес отличается от выходного IP, быстрый режим остановится на проверке.
5. После серверных проверок мастер покажет путь к файлу `proxy-IP.json`. Скопируй его с VPS по SSH и импортируй в **AmneziaVPN → добавить подключение → файл с настройками**. При входе под root можно выполнить на другом устройстве `scp root@АДРЕС_VPS:/root/nl-vpn-access/proxy-IP.json .`, подставив адрес VPS и имя файла, указанное мастером. Ссылка `vless://…` тоже будет доступна для совместимых клиентов. Храни профиль как ключ доступа.
6. На этом устройстве подключись и проверь внешний IP. Для второго VPS повтори с его прокси. Скачанные файлы различаются по выходному IP.

В выбранном файрволе должен быть разрешён входящий TCP-порт VPN, который покажет мастер. Результат локальных тестов и границы проверки указаны в [CHECKS.md](CHECKS.md).
