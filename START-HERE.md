# NL: одна команда после входа по SSH

**Версия v1.0.0.** Команда скачивания находится в [COMMAND.txt](COMMAND.txt).

1. Подключись по SSH к серверу с **Debian 13** под `root`. Если у тебя другой административный логин, после входа выполни `sudo -i`.
2. Скопируй одну строку из `COMMAND.txt` и выполни её на сервере. Копировать файлы с компьютера не потребуется.
3. Мастер сам скачает установщик и 3x-ui, подготовит нужные пакеты, определит адрес сервера и выберет свободный порт VPN.
4. Введи **IP, HTTP-порт, логин и пароль прокси** из Proxy-Seller. Пароль вводится скрыто. SSH-пароль повторно вводить не нужно.
5. Проверь показанные адреса и введи `INSTALL`. После установки и серверных проверок появится готовая строка `vless://…` — скопируй её в VPN-клиент.

Это быстрый режим для статического прокси: адрес подключения к нему должен совпадать с адресом выхода. Если они различаются или хочешь вход в прокси без пароля, используй расширенный мастер из README.md.

Адрес VPS обычно определяется автоматически. Если не получилось, мастер спросит его. Для VPN выбирается свободный порт 443 или 8443; если оба заняты, он попросит другой и не будет останавливать занимающие их службы.

Панель управления закрыта от прямого доступа из интернета. Инструкция для входа в неё сохранится на сервере в `/root/nl-vpn-access/panel.txt`. Ссылку подключения можно получить повторно:

```sh
cat /root/nl-vpn-access/NL.txt
```

**Выбранный TCP-порт VPN должен быть разрешён в существующем файрволе сервера и панели хостинга.** Их правила установщик не меняет. Порт панели 2053 открывать не нужно.

Комплект проверен локальными тестами. Полную установку на отдельной Debian 13 ещё предстоит проверить. Действующий NL и кабинет Proxy-Seller при подготовке не изменялись.
