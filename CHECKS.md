# Проверка комплекта — 1 ноября 2026

Проверки проводились локально на Windows. На действующие VPS установщик не запускался; приватный второй сервер не открывался. VPN-клиенты на Windows не устанавливались и не запускались.

В комплекте есть 43 автоматических теста (`python3 -m unittest -v test_install.py test_bootstrap.py`; для второй части нужен Bash). Они проверяют:

- отсутствие установки при запуске без `--install` / `--quick` и без явного подтверждения;
- отказ запуска на Windows, неверные IP/порты и занятый порт;
- отсутствие прямого запасного выхода в конфигурации HTTP-прокси, маршрут DNS и блокировку обычного UDP;
- запрет прямого доступа к частным IP в прямом режиме;
- согласованность идентификаторов профиля и сервера, отсутствие приватного ключа в ссылке;
- ограничение прав службы и исключение унаследованных переменных прокси;
- проверку хеша, отказ от ссылок, выхода из каталога и дубликатов в архиве;
- отказ перезаписывать файл с доступами;
- запись настроек SQLite с параметрами и устранение дубликатов ключа;
- пошаговый ввод адресов и портов с исправлением ошибок, в том числе занятого порта;
- отдельный вход по разрешённому IP без запроса и сохранения пароля прокси;
- сохранение специальных символов в пароле и остановку, если терминал не умеет скрывать ввод;
- выбор порта через вопрос или параметр запуска, отказ от неинтерактивной установки;
- отсутствие изменений VPN до явного подтверждения выбранных параметров;
- автоматический выбор свободного порта и адреса серверной стороны SSH, запасное определение адреса и переход к вопросу при неудаче;
- ввод только четырёх значений прокси в быстром режиме;
- остановку загрузчика при проваленной начальной проверке, отсутствие вызовов apt при уже установленных пакетах;
- установку недостающих пакетов с запретом обновления и удаления, проверку хеша загрузки, отказ запуска недокачанного или изменённого файла.

Все 43 теста прошли: 34 проверки Python и 9 проверок загрузчика через Git Bash. Сеть, apt и подготовка системы в тестах загрузчика подменены; настоящий apt не запускался. Синтаксис установщика проверен Python, загрузчика — Bash. Базовые запросы API панели и поля конфигурации ранее сверены с кодом официальной версии v3.11.0 и ранее работавшей настройкой этой версии. Отсутствие полей user/pass для прокси без парольного входа дополнительно сверено с [официальной документацией HTTP outbound Xray](https://xtls.github.io/en/config/outbounds/http.html).

Дополнительно проверен скачанный официальный архив amd64: его SHA-256 совпал с закреплённым значением, безопасная распаковка завершилась успешно, внутри найдены Linux-файлы панели, Xray и база geoip. Исполняемые файлы не запускались. Для arm64 закреплён хеш из метаданных официального выпуска; сам архив arm64 локально не распаковывался.

**Не проверено:** полноценная установка на Debian 13, запуск именно этой ограниченной systemd-службы, реальное прохождение трафика через созданный ею профиль. Серверные проверки встроены в установщик и будут выполнены при первом запуске. Внешний файрвол, клиентский kill switch и отсутствие утечек браузера требуют отдельной проверки с клиентского устройства.

Поэтому комплект пригоден для первого контролируемого запуска, но не представлен как уже испытанная производственная установка. Статус подключения нельзя считать успешным до серверных проверок и проверки с другого устройства.
